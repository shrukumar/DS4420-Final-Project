## DS4420 Machine Learning and Data Mining 2 Final Project by Shrutika Kumar, Gabrielle Bambalan, and Jackson Goodman
#### Machine Learning to Optimize Marathon Training

This project uses 3 different predictive models to analyze runner data.
1) Time-series/ARIMA to predict running distance based on previous distances. It uses a SARIMA model to capture weekly seasonality.
2) User-User Collaborative Filtering to find the most similar runners and form running-buddy recommendations based on geography, characteristics, and running performance
3) Bayesian Modeling to predict marathon finish times and find the most impactful predictors.


### Data:
Data sourced from a [Kaggle Dataset on Long Distance Running](https://www.kaggle.com/datasets/mexwell/long-distance-running-dataset?select=run_ww_2019_m.csv). Files are within the data folder (very large).


### How to Run:
Install dependencies and run notebooks. Each notebook operates separately and can be run in any order.
See notebooks for imports and necessary packages.
